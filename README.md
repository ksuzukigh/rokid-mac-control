# Rokid Glasses Mac Control

Rokid Glasses RV101の画面をMacに表示し、Wi-Fi・マウス・キーボードで操作するためのツールです。

## 主な機能

- 開発用5ピンケーブルを一度つなぐだけで、ADBのWi-Fi接続を設定
- `scrcpy`による画面表示とマウス操作
- RV101のホーム画面に合わせたキーボード操作
- 操作中にRokidのWi-Fiがオフになった場合の自動復旧
- Wi-Fi切断後の自動再接続と画面再表示

## キーボード操作

| キー | 動作 |
| --- | --- |
| `←` / `→` | 上段のアプリアイコンを移動 |
| `Enter` | 決定・起動 |
| `Esc` | 一つ前へ戻る |
| `H` | 中央のHomeへ戻る |
| `Shift` + `←` | 下段左のメモを開く |
| `Shift` + `→` | 下段右のアプリ一覧を開く |
| `Space` | 画面中央をタップ |
| 素早く`Space` 2回 | 画面中央をダブルタップ |

## 対応環境

- macOS
- Rokid Glasses RV101（ADB上の機種名: `RG-glasses`）
- Rokid開発用5ピンケーブル
- Homebrew

## 初回セットアップ

1. このリポジトリをMacへダウンロードします。
2. `セットアップ.command`をダブルクリックします。
3. Rokidを開発用5ピンケーブルでMacへ接続します。
4. `Rokid操作【Wi-Fi・マウス・キーボード】.command`をダブルクリックします。
5. macOSからアクセシビリティの許可を求められた場合は、ターミナルを許可してもう一度実行します。

接続後はケーブルを外して使えます。Rokidの再起動後やIPアドレス変更後は、開発用5ピンケーブルを一度接続して同じファイルを実行してください。

## 注意

同じWi-Fi内での個人利用を想定した最初の実用版です。Wi-Fi自動復旧は、この操作ツールを開いている間だけ働きます。
